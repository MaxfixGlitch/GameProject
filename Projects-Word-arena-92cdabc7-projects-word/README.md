# Казино «21» — блэкджек в браузере

Классический блэкджек на чистом HTML, CSS и JavaScript. Без сборки, зависимостей и бэкенда — достаточно открыть `index.html`.

> Игра на демо-фишки. Реальные деньги не используются.

## Возможности

- **Полные правила блэкджека**: 6 колод, шуз с автоматическим перемешиванием, дилер останавливается на 17 (включая мягкие 17).
- **Все основные действия**: «Ещё», «Хватит», «Удвоить», «Сплит» (до 4 рук, сплит тузов — по одной карте).
- **Выплаты**: победа 1:1, блэкджек с первых двух карт 3:2, ничья возвращает ставку.
- **Фишки** номиналом 25, 50, 100, 250 и 500 ₽, лимиты стола 25–2 500 ₽.
- **Демо-пополнение** на 1 000 ₽, если фишки закончились.
- **Статистика**: раунды, победы, поражения, ничьи, блэкджеки, оборот, лучший раунд.
- **Сохранение прогресса** в `localStorage`. Если закрыть вкладку посреди раунда, ставка вернётся на баланс.
- **Управление с клавиатуры**: `H` — ещё, `S` — хватит, `D` — удвоить, `P` — сплит, `Enter`/`Space` — раздать, `Esc` — закрыть окно.
- **Адаптивная вёрстка** для телефона, планшета и десктопа, звуковые эффекты (можно отключить).

## Запуск

Просто откройте `index.html` в браузере. Или запустите локальный сервер:

```bash
python3 -m http.server 8080
# http://localhost:8080
```

## Тесты

Логика игры покрыта автоматическими тестами: 400 случайных раундов со всеми действиями, детерминированные сценарии на выплаты, сплит, удвоение, поведение дилера и восстановление после перезагрузки.

```bash
npm install
npm test
```

## Структура

```
index.html          разметка стола, фишек и модальных окон
style.css           оформление: сукно, дерево, карты, адаптив
game.js             состояние игры, правила, анимации, звук, сохранение
tests/game.test.mjs автоматические тесты на jsdom
```
